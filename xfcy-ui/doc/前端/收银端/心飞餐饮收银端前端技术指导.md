# 心飞餐饮收银端前端技术指导

## 1 收银端需求概述

> 心飞餐饮收银端 为安卓pad点餐软件。主要为餐厅服务员为顾客提供点餐服务 主要功能包含：

- 服务人员登录
- 开桌点餐服务
- 菜品沽清 -> 剩余菜量的售卖预估 如果余菜不足 则本菜品将无法下单
- 收据 -> 根据不同查询条件匹配出店内订单流水


## 2 技术选型

### 2.1 技术选型分析

- 首先对于如今市面上的IOS 、安卓的程序开发框架、能用于开发的并不多，flutter 和React Native相对而言是目前比较有竞争力的框架。
- 考虑到跨平台以及性能方面，flutter 是由谷歌团队研发 使用dart 语言本身也是有优势的 而且flutter 本身是吸取了RN的经验之后的产物 性能上也是优与RN的
- 然后就是最重要的一点了、flutter是最近非常火的框架 目前很多的公司招聘也将flutter 作为加分项 所有我们有必要对flutter 技术进行学习和研究


### 2.2 fluter 简介

> Flutter第一次亮相于2015年5月Dart开发者峰会上，初始名字叫做“Sky”，后更名为Flutter，Flutter使用Dart语言开发，Dart是Google于2011年推出的新的计算机编程语言。

- 特点
- 由于Flutter选用了Dart作为其开发语言，Dart既可以是AOT（Ahead Of Time）编译，也可以是JIT（Just In Time）编译，其JIT编译的特性使Flutter在开发阶段可以达到亚秒级有状态热重载，从而大大提升了开发效率。
- 使用自带的高性能渲染引擎（Skia）进行自绘，渲染速度和用户体验堪比原生
- flutter自带UI小部件，开发者可快速构建精美的用户界面，以提供更好的用户体验。

## 4 核心代码解析
### 4.1 场景1- flutter 有状态widget的构建  
> Flutter中几乎所有的对象都是一个Widget也就是一个小的部件或组件 flutter常用的有状态和无状态
> 整个项目随处可见的widget类的 以下简单介绍实现代码
```
// 创建一个有状态widget类
class Index extends StatefulWidget {    // 创建一个名为Index的类并继承StatefulWidget
  const Index({ Key key }) : super(key: key); // 配置key供flutter内部计算使用

  @override  // 继承标识 - 以下方法是从StatefulWidget继承而来，需要重写
  _Index createElement() => new _Index(); //有状态widget 需要State类来实现动态数据更新
}
// 创建对应的State类 当调用setState更改_isFavorited的值时会出发框架重绘widget实现页面的动态更新
class _Index extends State<Index> {
  bool _isFavorited = true; // 创建一个类型为bool类型的变量 设置默认值为true

  changeHandle(){  // 更改变量_isFavorited 时调用
    setState((){  flutter 中如果要改变一个state 需要使用setState 去更改不能直接等号赋值
      _isFavorited = false;
    })
  }

  @override
  Widget build(BuildContext context) { // 使用build方法描绘最终展示到页面上的内容
    return new Text('demo');  // 输出文字'demo' 到页面上 这里实际代码中会使用 大量的 fluter内置组件去完成
  }  
}

```

### 4.2 场景2 - 页面导航按钮实现
> lib > widgets > Navigat.dart
```
// 使用flutter_redux插件提供的StoreConnector实现Store中的变量更新控制页面转换
StoreConnector( // 使用StoreConnector
    converter: (store) {  // 执行callBack时调用， 
      return () => store.dispatch('ind');  // 使用store.dispatch来更新数据
    },
    builder: (context, callback,) {
      return GestureDetector( // 使用Flutter提供的手势widget实现点击功能
        child:StoreConnector(  // 使用redux中提供的StoreConnector实现全局State的更新
            converter: (store) => store.state,
            builder: (context, count) {
              bool active =  false;
              if(count == 'ind' || count == 'meal' || count == 'acc'){
                active = true; //active 为是否点击状态的控制state true为当前点击项目高亮
              }
              // 返回 一个自定义的wigets 在不同状态展示不同的图表
              return new NavBut(url:['icon_tangdian_sel@2x.png','icon_tangdian_nor@2x.png'], navTit:'堂点', active: active); 
            }
        ),
        onTap: (){ // 点击事件 回调执行callback执行converter
          callback();
        },
      );
    }
),
```

## 5 部署运行指南  

安装 

- 打开 pubspec.yaml 窗口上方会出现三个按钮  点击pubget 获取相关插件

运行

- 使用 android studio 的模拟器或者USB链接真机 运行项目

编译打包

- 进入 android 目录 cd android

- 清理环境并下载包 ./gradlew clean

- 编译 ./gradlew build

- 打包 ./gradlew assembleRelease

- 输出apk文件
build/app/outputs/apk/release/app-release.apk
