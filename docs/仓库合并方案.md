# 心飞餐饮 · 前后端仓库合并方案

> 版本：v1.0｜日期：2026-11-22
> 目标：把前端仓库 `xfcy-ui` 合并进后端主仓库 `xfcy`，一个仓库管全部前后端代码，统一目录、忽略规则与提交纪律。
> 执行状态：**合并操作已完成并验证**；提交计划见第六章（待确认后执行）。

---

## 一、背景

合并前是两组独立仓库：

| 仓库 | 远端 | 内容 |
|---|---|---|
| `xfcy`（主仓库） | gitee `itxinfei/xfcy` | 后端 Maven 多模块微服务（23 模块） |
| `xfcy-ui` | gitee `itxinfei/xfcy-ui` | 前端四端：guanjia / yunyin / diancan / weixin |

本地把 `xfcy-ui` 克隆进了主仓库工作区，但它**仍带独立 `.git`**，主仓库并未真正跟踪——只是目录摆在一起，不是合并。

同时工作区里还有一份 `restkeeper-front/`：四端的旧版副本（`project-czg-*` 命名），是 `xfcy-ui` 改名前的内容，与 `xfcy-ui` 重复。

## 二、合并目标

1. 一个仓库管全部前后端，跨端改字段不用跨库找代码；
2. 目录结构、忽略规则、提交纪律统一；
3. 前端历史不丢：`xfcy-ui` 远端仓库保留为备份，本地 `.git` 移除后不影响远端。

## 三、合并后目录结构

```
xfcy/
├── restkeeper_common/          后端公共模块
├── restkeeper_gateway/         网关
├── restkeeper_service/         业务 provider（operator/shop/store/order/es + mq + job）
├── restkeeper_web/             BFF（cash/enterprise/operator + web_common）
├── xfcy-ui/                    前端四端（合入后由主仓库跟踪）
│   ├── xfcy-guanjia/           门店管理端（Vue2）
│   ├── xfcy-yunyin/            总部运营端（Vue + TS）
│   ├── xfcy-diancan/           顾客点餐（Flutter）
│   └── xfcy-weixin/            微信小程序（Taro）
├── docs/                       需求与方案文档
├── pom.xml                     后端聚合 POM
├── README.md / LICENSE / NOTICE
└── .gitignore
```

## 四、已执行操作（2026-11-22）

| 操作 | 对象 | 规模 | 结果 |
|---|---|---|---|
| 移除嵌套仓库 | `xfcy-ui/.git` | 93 文件 / 68 目录 | ✅ 已删，`xfcy-ui` 498 个文件完整 |
| 删除旧版前端 | `restkeeper-front/` | 497 文件 / 183 目录 | ✅ 已删，验证无信息损失 |

**删除前核查（restkeeper-front 无独有内容）**：

- 四端源码与 `xfcy-ui` 逐文件对应，仅目录名前缀不同（`project-czg-*-java-master` → `xfcy-*`）；
- 两份前端技术指导文档（微信端 / 收银端）经 `diff` 确认：把 `xfcy-ui` 版的「心飞餐饮」替换回「餐掌柜」后**逐字节相同**，即同一份文档的改名前后版本；
- 真正独有的只有 2 个 Flutter 构建产物（`xfcy-diancan/lib/app-release.apk`、`xfcy-diancan/餐掌柜.apk`），属构建产物，本不应进仓库；
- 结论：删除无信息损失。旧版如需找回，可从 `xfcy-ui` 远端改名前提交（`5c45387` 之前）恢复。

## 五、目录与忽略规范

- 前端各工程**自带 `.gitignore`**（guanjia / weixin 覆盖 `node_modules`、`dist`；diancan 覆盖 `.dart_tool`、`build` 等），合入后原样保留，无需主仓库重复定义；
- 主仓库 `.gitignore` 当前只有 `.idea / target / *.iml / out / gen`，建议补充：
  - `.DS_Store`（前端四端常见，避免 macOS 上冒出来）；
  - `.serena/`（工具配置目录，含 cache 与 local.yml，已自带 `.gitignore`，建议整体不提交）；
- 不提交构建产物：`dist/`、`build/`、`*.apk`、`node_modules/`（由各工程 ignore 覆盖）。
